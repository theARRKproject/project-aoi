# Portfolio-ready description

## Short description

**Project Aoi** is an in-progress personal AI assistant built around local language-model inference, a persistent SQLite conversation store, and retrieval of relevant long-term memories. The project explores how to keep a character's response style consistent while allowing conversations to carry context across sessions.

## CV version

**Project Aoi | Local AI Assistant (Personal Project, In Progress)**  
Developed and tested a Python-based conversational AI prototype using PyTorch, Qwen, SQLite, and SentenceTransformers. Worked on personality prompting, local model execution, persistent chat history, and semantic memory retrieval. Debugged tokenisation, model responses, database persistence, and retrieval logic. Full model-memory integration and deployment remain in development.

## Interview talking point

"I wanted an AI assistant that could run on hardware I control and keep useful context between sessions. I started with a local Qwen model, built conversation storage with SQLite, then tested semantic retrieval to select memories for each prompt. One of the biggest challenges was linking model outputs with saved history while keeping Aoi's personality stable. It's an active prototype, so I focus on showing the architecture and what I can prove with tests rather than claiming the final product is complete."
