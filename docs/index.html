[ 01 / THE IDEA ]

More than a chatbot.

The aim is an assistant that has a defined voice, keeps the thread of a conversation, and uses past information when it matters. This is an experiment in connecting those pieces, not a finished product.

[ 03 / SOURCE SNAPSHOT ]

What the code looks like.

This repository reconstructs the earlier experiments into readable, modular Python. The original historical code was not available. The SQLite and keyword demo are tested; the model path is experimental.

01 / PERSISTENCE

Keep both sides of the conversation.

A single transaction writes the user's message and the generated reply so the database cannot save half a successful exchange.

storage.py ↗
storage.pyPYTHON
# Save only after generation succeeds
with self._connect() as connection:
    connection.executemany(
        "INSERT INTO messages ...",
        [
            (conversation_id, "user", user_text, now),
            (conversation_id, "assistant", reply, now),
        ],
    )
02 / RETRIEVAL

Find notes that match the question.

An optional embedding model converts the question and notes into vectors, then ranks them by similarity.

retrieval.py ↗
retrieval.pyPYTHON
# Normalize vectors for cosine ranking
embeddings = model.encode(
    [query] + [m.content for m in memories],
    normalize_embeddings=True,
)
query_vector = embeddings[0]
scores = [query_vector @ vector
          for vector in embeddings[1:]]
